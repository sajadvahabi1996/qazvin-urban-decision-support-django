## Before making the repository public

For every dataset, document:

1. Original publisher or data provider.
2. Source URL or acquisition method.
3. Date of download or collection.
4. Coordinate reference system and any transformations applied.
5. License and whether public redistribution is permitted.
6. Required attribution text, if any.

Do not publish datasets that you do not have permission to redistribute. OpenStreetMap attribution for the map base layer does not establish the license of the other files in this repository.
